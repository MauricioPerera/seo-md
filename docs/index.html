Que tu IA escriba para SEO sin arruinar el texto

SEO.md es una forma simple y abierta de decirle a un agente de IA qué límites técnicos no puede cruzar — sin que eso lo obligue a repetir palabras de más o sonar forzado.

Ver en GitHub Cómo funciona

El problema con la IA y el SEO

Pedirle a un modelo "escribí corto, usá estas palabras clave, no menciones tal cosa" no funciona bien. Pasa una de dos cosas:

Repite de más

Si el chequeo exige que una palabra clave "aparezca sí o sí", el texto termina repitiéndola de forma forzada — lo que en SEO se conoce como keyword stuffing.

Suena raro

Si se prohíbe una palabra sin pensar en el contexto, la IA la esquiva con vueltas — frases incómodas solo para no activar un chequeo mal diseñado.

Nadie lo revisa

Sin una forma automática de verificar, cada título y descripción hay que revisarlos a mano — no escala con la cantidad de contenido que una IA puede generar.

Cómo funciona

SEO.md separa dos tipos de reglas muy distintas, y las trata distinto a propósito.

Límites que no se pueden cruzar

Cosas objetivas: el título no puede superar cierta longitud, una palabra clave no puede repetirse más de X veces. Se verifican con un script, automáticamente — si algo se pasa, se corrige antes de publicar.

Guías de estilo

Cosas que necesitan criterio: para quién es el contenido, qué tono usar, qué historia contar. Esto se le explica a la IA en texto normal — no se fuerza con un chequeo automático, porque forzarlo es lo que rompe la calidad.

¿Para quién es esto?

Para cualquiera que use IA para escribir contenido web y quiera un mínimo de calidad garantizada — sin tener que revisar cada línea a mano.

Equipos de marketing

Definen sus reglas una vez (largo de título, palabras clave, tono) y cualquier agente de IA las respeta después, sin tener que repetir la instrucción cada vez.

Desarrolladores

Un archivo de texto simple + un script que se puede correr en cualquier proyecto, sin librerías pesadas ni configuración compleja.

Agencias

Un mismo protocolo para todos los clientes, con sus propias reglas por proyecto — consistencia sin perder lo particular de cada marca.
